# Privacy

The privacy policy is a page on the site itself:
**https://post-map.vercel.app/privacy** — also reachable from the
*Credits & licence* block at the bottom of the sidebar.

That page is the canonical wording. It is not reproduced here, because a second
copy is a copy that drifts; this file exists so that anyone reading the
repository on GitHub can find where the policy lives. The source is
[`app/privacy/page.tsx`](app/privacy/page.tsx), and its git history is the
change log.

The short version: no accounts, no cookies, no third-party trackers, and
nothing you type is sent anywhere. Vercel Web Analytics and Speed Insights
record anonymous page views and load timings on Vercel's free tier. See the
page for what that covers in full.
